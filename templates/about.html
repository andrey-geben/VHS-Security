VHS-Security — слой охраны поверх VHS-Streamer и VHS-Viewer: карта объекта, камеры, зоны обзора, события и тревоги.

Связка модулей VHS

Streamer отдаёт камеры и видеопотоки. Viewer агрегирует один или несколько Streamer, выполняет аналитику и передаёт камеры/события в Security. Security показывает объект, тревоги и снимки.

StreamerНастройки → Безопасность → «Ключ интеграции». Этот ключ нужен Viewer и Security для /api/integration/streams.
ViewerНастройки → «Серверы VHS-Streamer»: URL и ключ каждого Streamer. Несколько записей = несколько Streamer.
ViewerНастройки → «Внутренний API и ключи»: ключ Viewer для Security.
SecurityНастройки → «Интеграция VHS»: Viewer URL, ключ Viewer, Streamer URL и ключ Streamer.

Единый заголовок — X-VHS-Key; поддержаны X-Ingest-Token и X-API-Token. Security читает /api/integration/state, /api/integration/events и снимки Viewer. Проверка: /api/integration/info у каждого модуля. Порты не публикуйте в интернет — используйте WireGuard/VPN.
