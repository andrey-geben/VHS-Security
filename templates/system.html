Как это связано

Streamer отдаёт камеры и события, Viewer агрегирует один или несколько Streamer и передаёт номера/объекты, Security показывает карту и журнал.

1. Streamer«Настройки → Безопасность → Ключ интеграции».
2. Viewer«Настройки → Серверы VHS-Streamer»: URL + ключ каждого Streamer; «Внутренний API и ключи»: ключ Viewer для Security.
3. Security«Настройки → Интеграция VHS»: Viewer URL, ключ Viewer, при необходимости Streamer URL и ключ.

Заголовок: X-VHS-Key (совместим с X-Ingest-Token и X-API-Token). Проверка: /api/integration/info у Streamer, Viewer и Security.
